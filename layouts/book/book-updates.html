What changed

Chapter 51 — Vector Search with pgvector

A complete new chapter covering vector embeddings and nearest-neighbor search in PostgreSQL using the pgvector extension.

  • HNSW and IVFFlat index types — when to use each and how they work
  • Vector distance operators: cosine, L2, inner product
  • Hybrid search: combining vector similarity with relational filters
  • Practical patterns for semantic search on real data

56 New Figures

All 56 figures are generated from SQL and PostgreSQL system data using TikZ — they are derived from the database itself, not drawn by hand. They illustrate plan node types, join strategies, index structures, normalization concepts, and data distribution patterns.

PostgreSQL 12–18 Coverage

New features introduced across PostgreSQL versions 12 through 18 are covered where they apply to the book's topics:

  • GENERATED ALWAYS AS (expr) VIRTUAL — virtual generated columns (PG 12+)
  • RETURNING OLD / RETURNING NEW — before/after values in DML (PG 17)
  • uuidv7() — time-ordered UUID generation (PG 17)
  • NULLS NOT DISTINCT in unique constraints and indexes (PG 15)
  • Incremental sort — planner optimisation for partially-sorted input (PG 13)
  • Logical replication improvements, improved EXPLAIN output, and more

Fully Integrated Companion Lab

The lab is now a first-class part of the book. One command starts a complete PostgreSQL environment with all datasets pre-seeded:

docker compose up -d

Open localhost:8042 to reach an interactive query pane organised by book chapter — every SQL query from the book is there, ready to run, edit, and experiment with. No account required beyond Docker. Learn more about the lab →
