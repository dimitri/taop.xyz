How it works

PostgreSQL in your browser, courtesy of PGLite

The interactive SQL runner is powered by PGLite — a WebAssembly build of PostgreSQL that runs entirely inside your browser tab. No server, no cloud connection, no data leaving your machine.

What happens when you open a lesson

  1. PGLite (~12 MB WASM) loads in a Web Worker
  2. The lesson's dataset (f1db, Chinook, or Pagila) loads from a compressed file
  3. A real PostgreSQL 16 instance is live — all queries run against it
  4. Results appear in a table below each query card
Desktop only. The WASM module and datasets are substantial enough that mobile would be a poor experience — on phones the lesson shows the static queries and links you to the full app.
Coming soon — Persistent PostgreSQL. Need your own schema, your own data, your own extensions? A persistent cloud PostgreSQL session will be available as a paid add-on, for learners who want to go beyond the curated datasets.

What PGLite actually is

  • A real PostgreSQL 16 build compiled to WASM by ElectricSQL
  • Runs in a dedicated Web Worker — never blocks the page
  • Supports the full SQL dialect: window functions, CTEs, range types, EXPLAIN, everything
  • Dataset is a compressed SQL dump, loaded and executed once on first open
  • Persists in IndexedDB between page reloads

What it does not support

  • Extensions requiring OS-level libraries (PostGIS, pgvector, pg_trgm)
  • Network access or replication
  • Very large datasets — the f1db is kept under 10 MB compressed
