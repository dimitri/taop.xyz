Built for working developers.

This masterclass session is not for beginners. It assumes you write SQL in production — SELECT, JOIN, GROUP BY — and you want to go further without reading the documentation alone.

This is for you if you are…

  • A backend developer who writes SQL queries in your application layer
  • A data engineer who reaches for Python when SQL gets complex
  • A tech lead who wants your team to write better, faster queries
  • A developer who's read about window functions but never felt confident using them

This is not for you if you are…

  • New to SQL — start with the book first
  • Looking for a database administration course
  • Working with a database other than PostgreSQL
