Aggregation is where most SQL bugs live — join amplification, missing NULLs,
HAVING confusion. These lessons cover how GROUP BY really works, the FILTER
clause for multiple counts in one pass, and the advanced grouping features
(GROUPING SETS, ROLLUP, CUBE) that replace repeated queries.
