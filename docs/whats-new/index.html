pgcopydb

Parallel, resumable PostgreSQL-to-PostgreSQL migration. Clones a running database — schema, data, sequences, indexes, large objects — without a maintenance window. v0.18 released July 2026.

pg_auto_failover

High-availability automation for PostgreSQL: a monitor service orchestrates health checks and failover, maintaining write availability across node failures and replica promotions.

pgcopydb, pg_auto_failover, and pgloader are free open-source software. If they save your team time, GitHub sponsorship helps keep them maintained.

pgloader

Rewritten from Perl to Common Lisp for parallel loading and extensibility. Migrates data into PostgreSQL from MySQL, SQLite, MS SQL Server, CSV, and other sources — handling type coercion, constraint creation, and schema generation automatically.
