Pick the right type: relational basics, ranges and constraints, and when JSON earns its place.

PostgreSQL’s rich type system lets the database enforce correctness for you — from serialization and deserialization at the application boundary to ranges, exclusion constraints, and the considered use of JSON.

    A database is not a place to dump strings and parse them back. Its type system is the contract that keeps your data consistent across every part of your application.
