Extensions & PostGIS

Extend PostgreSQL: hstore, trigrams, HyperLogLog, and real geospatial queries with PostGIS.

PostgreSQL is a platform, not just a database. Extensions add full-text fuzzy search with trigrams, approximate counting with HyperLogLog, key/value auditing with hstore — and with PostGIS, true geospatial queries and nearest-neighbour search.

  • k-Nearest-Neighbour Search with <->

    "Find the closest N things to here" is a one-line ORDER BY in PostgreSQL — and with a GiST index it answers in microseconds.

    #PostGIS #GiST #KNN

  • A Map With No Graphics Library

    Bin points into a grid, count them, and encode density as Braille height-bar characters — four dot-fill levels on fixed thresholds, and PostgreSQL draws a recognizable map straight into the query result.

    #GROUP BY #generate_series #string_agg
